# 文档书写规范

> 状态：生效中
> 摘要：这个 docs/ 目录里所有文档的写法约束——分层、状态行、命名、什么能改什么不能改

这份文件规则最少但最容易被违反。违反的后果是：文档看着齐全，三个月后没有一条敢信。

---

## 1. 分层：一份文档只承担一层

| 内容 | 归属 | 反例 |
| --- | --- | --- |
| 要什么功能、做到什么算完 | `projectneed.md` | 里面写了"用 PostgreSQL" |
| 为什么选它、否掉了什么、代价是什么 | `decisions/` | 写在代码注释或聊天记录里 |
| 模块划分、表结构、接口契约、架构图 | `design/` | 混进 PRD |
| 某一块要怎么改、改坏怎么回滚 | `refactor/` | 直接动手改代码 |
| 现在正在做什么、下一步 | `NOW.md` | 写进 INDEX.md |

**判断方法**：把技术选型名词全部删掉，这段内容还剩意义吗？剩——它属于需求层；不剩——它属于设计或决策层，别留在 `projectneed.md`。

架构约束确实要在需求层保留，但翻译成产品语言：

- ✗ `数据存 PostgreSQL，手机本地 Room 做缓存`
- ✓ `数据不能只存在一台设备上；换机后能完整找回；网络不可用时历史内容仍可读`

后者不绑定任何实现，实现换了它也不用改。

## 2. 头部两行是硬约定

每份文档第一行标题，紧跟一个引用块，至少两行：

```markdown
# ADR-0003：主存储放在服务端

> 状态：生效中
> 摘要：数据与接口都放服务端，客户端只做展示与离线缓存
```

这两行没有脚本兜底，全靠你抄进 [INDEX.md](INDEX.md) 的清单表。缺了这两行的文档等于没进目录——三个月后没人找得到它。

状态取值只有四个，不要自创：

- `草案` — 内容未定，不作为依据
- `生效中` — 当前结论
- `待复审` — 曾经生效，已察觉可能不成立
- `已废弃（被 NNNN 取代）` — 保留原文，仅供考古

状态回答的是「这篇能不能作为依据」，不是「事情做完没有」。故障台账最容易混：未闭环挂 `草案`，复盘定稿改成 `生效中`，处置进度写在正文的预防措施表里，不占这个字段。

## 3. ADR 是历史快照，不是活文档

已生效的 ADR 正文**不修改**。方案变了就新开一条，旧条目只改状态行并写明被谁取代。

理由：ADR 的价值是"当时知道这些信息、所以做了这个判断"。改了就变成事后诸葛亮，也就查不出当初为什么否掉那个方案了。

唯一例外：纯笔误、链接失效、错别字。

## 4. 备选方案表是 ADR 的核心，不能省

一份没有"否掉过什么"的 ADR 只是把结论又抄了一遍。至少写两个被考虑过的方案，各自的代价与否决理由要写实——写"太复杂"没用，写"要自己处理多端写冲突，现阶段扛不起这块维护成本"才有用。

同时写**复查条件**：出现什么情况时这条决策作废。这是防止旧结论长期挡路的主要手段。

## 5. 结论在前

第一段就要给出结论，不要背景铺三屏才说"所以我们选了 A"。背景放结论后面。

## 6. 命名

- ADR：`NNNN-短横线英文名.md`，编号从 0001 起，只增不复用。
- design / refactor：`主题名.md`，一个主题一份，写满就拆，不攒长卷。
- 模板：`templates/<类型>.md`，只放格式，不放项目专有内容。模板自带的 `状态：草案` 是提醒你复制成新文档后按实际改掉，不是让新文档一直挂着草案。

## 7. 数字要标性质

写量级就注明是估算：「单条约 2KB（估算）」「冷启动 1.4s（实测）」。两者混在一起写，后面没人敢按它做判断。

## 8. 篇幅上限

- `NOW.md` ≤ 60 行。超了说明它在承担历史职责，把已完成的部分挪进对应文档。
- 单篇 ADR 通常 20–60 行就够。写不动往往意味着这是两个决策，拆成两条。

## 9. 禁止事项

- **可定位到具体机器或个人的标识值不写进 `docs/`**——IP、域名、主机名、端口、账号与家目录路径、密钥口令，一律只写性质不写值。这类文档会被复制、被同步、被贴给别人，一旦写进去就跟着仓库公开。
  - ✗ `服务器 192.168.x.x，4 核 8G，本地跑不动模型`
  - ✓ `自建服务器约 4 核 8G 量级，本地推理不可行`
  - 硬件规格（核数、内存量级）本身不是标识值，可以留；能和"是哪一台/是谁"关联上的那部分不能留。
- 不建空文档凑结构。目录不全没关系，有内容才写。
- 不写没有对应文档的待办——要么进 `NOW.md`，要么进 milestone/PRD 的待确认项。
- 不在正文里复制另一篇的内容，用链接。
- 不把 `<尖括号占位>` 留在交付文档里。
- 不用日期当唯一标识——同一天可能有三条 ADR。
